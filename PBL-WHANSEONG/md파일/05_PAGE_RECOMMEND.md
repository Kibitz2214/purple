# 05. 추천 결과 UI 반영

- 브랜치: `feat/recommendation`
- 선행 조건: `04_RECOMMEND_LOGIC` 완료 (같은 브랜치 내 이어서 작업)
- 완료 후: `dev`에 머지

## 목적
`RecommendService.recommend(student)` 결과를 화면에 노출해
학생이 추천 과목을 바로 확인하고 신청까지 이어갈 수 있게 한다.

## 배경
기존 `courses.html`은 전체 개설 강의 목록(검색/필터/정렬)을 보여준다.
추천 화면은 별도 영역(마이페이지 확장 또는 신규 탭)으로 구성한다.

## 작업 항목
- [ ] 추천 목록 노출 위치 결정 (`my.html` 상단 섹션 vs 신규 `recommend.html`)
- [ ] 컨트롤러에 추천 목록 모델 추가 (`CourseController` 또는 신규 컨트롤러)
- [ ] 추천 카드/리스트 UI (과목명, 교수명, 학점, 이수구분, 시간, 정원 현황)
- [ ] "바로 신청" 버튼 → 기존 수강신청 로직(`EnrollmentController`) 연동
- [ ] 추천 사유 표시 (예: "전공필수 3학점 부족")

## 완료 조건 (Definition of Done)
- 로그인 학생별로 추천 목록이 다르게 표시됨
- 추천 화면에서 클릭 한 번으로 수강신청까지 가능
- 부족 카테고리가 없는 경우 "추천 과목 없음" 안내 표시
