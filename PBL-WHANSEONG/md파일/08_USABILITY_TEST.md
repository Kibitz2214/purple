# 08. 사용성 테스트

- 브랜치: `dev`
- 선행 조건: `07_INTEGRATION_TEST` 완료 (기능적으로 안정된 상태)
- 완료 후: `09_FEEDBACK_FIX`로 진행

## 목적
실제 사용자(팀원 외 학생 등)가 졸업요건 확인 → 추천 → 수강신청 흐름을
직접 사용해보고 UX 관점의 문제를 찾는다.

## 대상 및 방법
- 대상: 팀원이 아닌 제3자 (동료 학생 등) 최소 인원 확보
- 방법: 사전 시나리오 없이 자유 탐색 + 핵심 과업 수행 요청
  1. "본인 학과 기준으로 부족한 이수구분을 찾아보세요"
  2. "추천 과목 중 하나를 신청해보세요"
  3. "방금 신청한 과목에 강의평가를 남겨보세요"

## 수집 항목
- 과업 성공/실패 여부, 소요 시간
- 헷갈렸던 지점 (문구, 배치, 색상/강조 등)
- 개선 요청 사항 (자유 의견)

## 작업 항목
- [ ] 테스트 참여자 모집 및 일정 확정
- [ ] 관찰/설문 결과 기록 양식 준비
- [ ] 테스트 진행 및 결과 정리

## 완료 조건 (Definition of Done)
- 최소 N명 이상의 테스트 결과 기록 완료
- 개선 항목이 우선순위와 함께 목록화되어 `09_FEEDBACK_FIX`로 전달 가능한 상태
