# 03. 미이수 과목 표시 화면 (마이페이지 확장)

- 브랜치: `feat/analysis`
- 선행 조건: `02_ANALYSIS_SERVICE` 완료 (같은 브랜치 내 이어서 작업)
- 완료 후: `dev`에 머지

## 목적
`my.html`(마이페이지)에 졸업요건 이수 현황 체크리스트를 추가해
학생이 자신의 부족한 이수구분/학점을 한눈에 볼 수 있게 한다.

## 배경
현재 `my.html`은 신청 내역(시간표) · 신청 학점 합계만 표시.
`AnalysisService.analyze(student)` 결과를 컨트롤러에서 모델에 담아 뷰에 전달한다.

## 작업 항목
- [ ] `CurrentStudentResolver`로 현재 로그인 학생 조회 (기존 방식 재사용)
- [ ] 마이페이지 컨트롤러(`AuthController` 또는 신규 컨트롤러)에 `GraduationStatus` 추가
- [ ] `my.html`에 이수 현황 섹션 추가
  - 이수구분별 진행률 바 (취득/요구 학점)
  - 부족 학점이 있는 카테고리는 강조 표시
  - 총 이수 학점 / 졸업 요구 학점 요약
- [ ] `style.css`에 진행률 바 스타일 추가

## 완료 조건 (Definition of Done)
- 마이페이지 접속 시 이수구분별 부족 학점이 화면에 정상 표시
- 요건을 모두 충족한 학생은 "졸업 요건 충족" 상태로 표시
- 기존 신청 내역/시간표 UI와 레이아웃 충돌 없음
