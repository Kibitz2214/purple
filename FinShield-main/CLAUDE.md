# FinShield 프로젝트

## 프로젝트 개요
**FinShield** (Finance + Shield)
금융 취약계층을 위한 AI 기반 지능형 금융사기 예방 서비스

## 팀 정보
- **팀명**: FinShield
- **과제명**: AI 기반 금융사기 예방 시스템
- **팀장**: 황승구
- **팀원**: 이지훈, 조환성, 조원준, 몽흐벌드, 아말자르갈
- **지도교수**: 김광수
- **수행기간**: 2026년 3월 13일 ~ 2026년 12월 18일

## 주요 기능
1. 개인 맞춤형 AI 기반 이상 거래 탐지 (FDS)
2. 설명 가능한 AI (XAI) 위험 스코어링
3. 참여형 사기 신고 및 블랙리스트 시스템
4. 인지 유도형 안전 UI
5. 보호자 교차 승인 시스템

## 정량적 목표
- 사기 탐지 정확도: 90% 이상
- 시스템 응답 속도: 3초 이내
- 블랙리스트 업데이트: 주 1회 자동화

## 기존 서비스와의 차별점
| 구분 | FinShield | 기존 금융앱 |
|---|---|---|
| 사기 대응 시점 | 송금 이전 사전 예방 | 사후 탐지 |
| 사용자 행동 개입 | 경고/승인 요청/행동 제한 | 경고 제공 정도 |
| 설명 가능성 | XAI 기반 구체적 근거 | 단순 점수 |
| 대상 특화 | 금융 취약계층 맞춤 | 일반 사용자 |

## 프로젝트 구조
```
FinShield/
├── FinShieldBackend/      ← 백엔드 (Python/FastAPI)
│   ├── main.py
│   ├── core/              ← JWT 인증 의존성
│   ├── crud/              ← DB CRUD 로직
│   ├── database/          ← TiDB / MongoDB 연결
│   ├── models/            ← SQLAlchemy 모델
│   ├── routers/           ← API 엔드포인트
│   └── schemas/           ← Pydantic 스키마
└── FinShieldFrontend/     ← 프론트엔드 (React Native/Expo)
    ├── app/               ← Expo Router 화면
    ├── components/        ← 공통 컴포넌트
    ├── constants/         ← 상수·디자인 시스템
    └── hooks/             ← 커스텀 훅
```
